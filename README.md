# API отзывов из 2ГИС и Яндекс Карт

Backend собирает отзывы об организациях, приводит данные разных источников к одной схеме и выдаёт их клиентским сайтам через REST API.

## Задача

Несколько сайтов должны получать отзывы своих компаний и филиалов, не смешивая данные между клиентами. Источники используют разные поля и могут временно отвечать с ошибками, поэтому синхронизация должна быть повторяемой и не создавать дубликаты.

## Что реализовано

- несколько проектов, организаций и источников в одной системе;
- адаптеры 2ГИС и Яндекс Карт с общей моделью отзыва;
- сохранение автора, оценки, текста, дат, фотографий и видео;
- обновление существующих отзывов без дублей;
- фоновые синхронизации, история запусков, повторные попытки и журнал ошибок;
- отдельный Bearer-ключ для каждого клиентского проекта;
- административный API с отдельным ключом;
- PostgreSQL, миграции, Docker, тесты и CI.

Для 2ГИС доступен браузерный режим: сервис открывает публичную страницу отзывов в Chromium и читает ответы веб-приложения. CAPTCHA не обходится и записывается как ошибка синхронизации.

## Моя работа

Я спроектировал общую модель данных, изоляцию клиентов и интерфейс адаптеров, реализовал API, хранение, плановый запуск и обработку ошибок. Новый источник можно добавить отдельным адаптером без переделки базы и клиентского API.

## Стек

Python, FastAPI, PostgreSQL, SQLAlchemy, Alembic, Playwright, Docker, Pytest, Ruff.

## Запуск

~~~bash
cp .env.example .env
docker compose up --build
~~~

Перед запуском нужно заменить административный ключ и служебные секреты в .env. После старта доступны:

- API: http://localhost:8000
- Swagger: http://localhost:8000/docs
- проверка состояния: http://localhost:8000/health

Плановую синхронизацию можно вызывать из cron:

~~~bash
docker compose run --rm api rew-api sync-due
~~~

## Проверка

~~~bash
python -m pip install -e ".[dev]"
python -m playwright install chromium
pytest
ruff check .
~~~

## Статус и ограничения

Проект готов к развёртыванию, но автоматический сбор нужно использовать с учётом правил и разрешений владельцев источников. Изменения страниц 2ГИС или Яндекс Карт могут потребовать обновления соответствующего адаптера.
